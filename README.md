# Musical on Ice — сайт

Статический сайт: один `index.html`, админка и папка с афишами. Тексты и афиши живут в `site/content.json`, его правит админка.

```
site/
  index.html      сайт
  admin.html      админка: тексты, афиши, видео
  content.json    все тексты сайта
  images/         афиши шоу
.github/workflows/deploy.yml   автоматическая выкладка
```

## Как включить автоматическую выкладку — один раз

1. Создайте репозиторий на GitHub и загрузите в него содержимое этой папки.
2. В репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. Сделайте любой коммит в ветку `main`. Во вкладке **Actions** пойдёт сборка, через минуту сайт будет доступен по адресу вида `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Дальше каждый коммит в `main` выкладывается сам. Вручную запустить сборку можно кнопкой **Run workflow** во вкладке Actions.

## Как править тексты без программиста

1. Откройте `admin.html` — на сайте по адресу `…/admin.html` или локально.
2. Раздел **Публикация на сайт** заполняется один раз:
   - владелец репозитория, название, ветка `main`, путь `site/content.json`;
   - токен: **GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens**. Доступ — только к этому репозиторию, право **Contents: Read and write**.
3. Правьте тексты и нажимайте **Опубликовать на сайт**. Админка отправляет `content.json` в репозиторий, GitHub пересобирает страницы.

Токен хранится только в браузере редактора. Если админка не должна быть публичной — удалите `site/admin.html` из репозитория и запускайте её локально: положите рядом с `content.json` и откройте через локальный сервер.

## Локальный просмотр

```bash
cd site
python3 -m http.server 8000
```

Сайт — `http://localhost:8000`, админка — `http://localhost:8000/admin.html`.

Простым двойным кликом `index.html` тоже открывается: тогда он берёт запасную копию текстов, вшитую внутрь файла, а админка работает только на выгрузку файла.

## Свой домен

**Settings → Pages → Custom domain**, затем у регистратора домена пропишите записи, которые покажет GitHub. Файл `CNAME` создастся сам.
